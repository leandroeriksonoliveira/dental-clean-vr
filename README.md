# Dental Clean VR

Site institucional da clínica **Dental Clean** — Dr. Joel Junior RT, especialista em Ortodontia em Volta Redonda/RJ.

**Produção:** [dental-clean-vr.vercel.app](https://dental-clean-vr.vercel.app)

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Conformidade

O site segue as diretrizes do CFO/CRO/RJ e LGPD:

- Identificação profissional (CRO/RJ 19.478 · EPAO 4.963)
- Disclaimer informativo em todas as seções
- Política de Privacidade (`/privacidade`)
- Banner de consentimento de cookies
- Sem depoimentos, preços ou promessas de resultado

## Deploy

Conectado ao Vercel via GitHub: `leandroeriksonoliveira/dental-clean-vr`

```bash
npx vercel deploy --prod
```
